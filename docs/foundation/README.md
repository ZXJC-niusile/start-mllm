# 基础篇总览

如果你是一名为刚掌握 Python 基础语法，面对各种教程中复杂的命令行、虚拟环境、文件路径和庞大的深度学习框架感到困惑的学习者，那么这个“基础篇”就是为你准备的。

很多多模态大模型（MLLM）的新手，其实并不是卡在“听不懂模型原理”上，而是卡在“连项目和环境都跑不起来”的工程基础环节。当你满屏看到 `FileNotFoundError` 或者 `ModuleNotFoundError`，却不知道是该换目录、换环境还是换代码时，任何高深的模型知识都会变成巨大的挫败感。

**基础篇不是“速通”，而是为你扫平后续学习 MLLM 所需的最低工程与模型基础。** 我们不要求你一上来就理解复杂的 Transformer 和深度学习，而是从“你在哪里运行代码”开始，一步步把基础打牢。
