# 06 Transformer 基础：让每个位置读取上下文

前置：[05 Embedding 与 Tokenizer](./05-Embedding与Tokenizer.md)。已知文本能变成 `[B,T,D]` 的向量序列，现在的问题是：一个位置怎样利用其他位置的信息？本章解释注意力和生成过程，不新增训练实作、习题或答案。

原始 [Transformer 论文](https://arxiv.org/abs/1706.03762)研究的是 encoder-decoder 架构。理解它的组成有助于阅读后来的模型，但不能把原论文的全部配置直接当成现代 decoder-only LLM 的配置。下面先用单头、自注意力和简化形状介绍共同原理。

## 6.1 为什么逐 token 的线性层还不够

若对每个 token 都独立执行同一个 `xW+b`，当前位置不能读取其他位置，因而无法用前文判断代词指向或词语含义。注意力让每个位置根据输入内容，给可读取的位置分配权重，再汇总它们的信息。

这不是把所有 token 永久压成一个句向量：每个查询位置都会得到自己的汇总结果，所以输出仍保留序列轴。不同层可在已更新的表示上再次交互。

## 6.2 Q、K、V 是三种投影，不是三个词表

暂略批轴，输入 `X` 为 `[T,D]`，用三组可学习权重得到：

```text
Q = XWq    [T,dₖ]    查询：当前位置用什么特征寻找信息
K = XWk    [T,dₖ]    键：每个位置用什么特征参与匹配
V = XWv    [T,dᵥ]    值：被读取时提供什么内容
```

Q 和 K 的最后一维必须一致，才能做点积。第 `i` 个 query 与第 `j` 个 key 相乘求和，形成 `S[i,j]`；所有位置一起计算为 `S=QKᵀ/√dₖ`，形状 `[T,T]`。行表示“谁在读”，列表示“读谁”。除以维度平方根用于控制点积的尺度。

`Wq/Wk/Wv` 是参数，Q/K/V 是本次输入投影出的中间结果。注意力不是直接比较两个 token ID，也不是预先固定的语法规则。

## 6.3 softmax 与加权求和

对分数矩阵的每一行做 softmax，得到权重 `A`。每行在允许的位置上合计为 1，随后计算 `O=AV`，形状 `[T,dᵥ]`。输出第 `i` 行就是按该行权重混合各位置的 value。

例如某一 query 对两个位置的缩放后分数为 `[ln(3),0]`，softmax 得到 `[0.75,0.25]`。若两个 value 为 `[2,0]` 和 `[0,4]`，汇总结果是 `[1.5,1]`。这里是人工构造的计算示意，不是某个词在真实模型中的注意力记录。

注意力权重描述这次计算如何汇总信息，不自动构成答案的忠实解释。多层投影、残差和后续变换都会影响最终输出，不能仅看一张注意力热图就断言模型推理依据已经被证明。

## 6.4 因果 mask 与 padding mask

下一 token 预测不能偷看未来真实答案。对第 `i` 个位置，因果自注意力只允许读取 `j≤i` 的位置；可在 softmax 前把其他分数设成负无穷，使对应权重为 0。三位置的可见性如下：

| 查询位置 | 可读位置 |
| --- | --- |
| 0 | 0 |
| 1 | 0、1 |
| 2 | 0、1、2 |

先 softmax 再把部分权重置零，如果不重新归一化，就不再是同一种计算。整行没有任何可读位置还会导致数值问题，实际 mask 构造必须保证有效查询有合理的读取范围。

padding mask 则屏蔽凑批补齐的位置，与时间上的“未来”无关。两种约束可以组合。视觉编码器常允许图像 patch 之间双向读取；语言解码器的因果规则不能直接套到所有视觉模块上。

## 6.5 多头注意力与位置表示

多头注意力让多组投影并行计算不同的交互，再拼接并投影回模型宽度。典型均分示例中，`D=8`、头数为 2，每头宽度为 4；每头分数仍是 `[T,T]`，拼接后的特征宽度回到 8。头数不是 token 数，也不保证每个头都可解释为一种固定语法功能。

Q/K/V 投影本身不告诉模型序列顺序。位置编码把位置信息纳入计算：原始论文讨论了正弦位置编码与可学习位置表示；后来的模型还使用相对位置或旋转位置编码等方案。RoPE 可理解为根据位置旋转 query/key 的成对分量，使点积携带相对位置信息，但不能因此假定所有长度都能无损外推。

二维图像还有行列位置，多图和视频还涉及图片边界与时间。具体 MLLM 如何编码这些信息，应查其架构，而不是统一加一条文本位置编号就算完成。

## 6.6 一个 Transformer block 不只有注意力

注意力负责位置之间的信息交互，前馈网络（FFN/MLP）通常对每个位置的特征做非线性变换。残差连接把输入加回变换结果，例如 `X + F(X)`，所以被相加的张量形状必须一致；它为信号和梯度提供直接路径。

LayerNorm 等归一化模块调节特征尺度；常见的 LayerNorm 在单个位置的特征轴上计算统计量，不能误读为把整批样本混在一起求均值。现代模型也可能采用 RMSNorm。归一化在子层之前还是之后，以及激活、偏置和门控的设计，会随架构变化。

一个常见的 pre-norm 示意是：

```text
H = X + Attention(Norm(X))
Y = H + MLP(Norm(H))
```

这是结构示意，不是适用于所有模型的完整实现。多层 block 叠加后，最后的隐藏表示通过词表输出头变成 logits，才进入下一 token 选择。

## 6.7 Encoder、decoder 与 cross-attention

Encoder 通常用双向上下文构建输入表示。原始 encoder-decoder Transformer 的 decoder 除了因果自注意力，还用 cross-attention 读取 encoder 输出：Q 来自 decoder，K/V 来自 encoder。如果查询长度为 `T`、输入记忆长度为 `N`，分数矩阵是 `[T,N]`。

Decoder-only LLM 通常在一条序列上做因果自注意力，没有原始结构里那套单独的文本 encoder。MLLM 既可以把视觉向量接入这条序列，也可以安排独立的跨模态读取模块。这两类连接方式不能仅凭“都使用 Transformer”混为一谈。

## 6.8 并行学习、逐步生成与 KV cache

训练时，真实前缀已经在样本里，可以在因果 mask 下并行计算多个位置的损失，称为 teacher forcing。生成时下一 token 尚未知，模型需要选出一个，再继续下一步。贪心选最大分数，采样则依据分布抽取；温度和 top-p 改变候选分布，不是事实校验机制。

在标准因果 decoder 中，过去位置不会读取未来新 token，因此可以缓存各层过去位置的 K/V，避免每一步重复计算整段前缀。缓存节省重复工作，但占用随序列长度增长的内存；它既不是模型参数，也不是保存所有注意力权重的表。

普通完整自注意力的分数矩阵随 `T²` 增长，这解释了长序列成本为何敏感，但不代表任何实现都显式存储完整矩阵，也不意味着整模型耗时严格按平方变化。图像引入的大量视觉位置会影响预算，这正是后续视觉压缩与连接器设计的重要动机。
