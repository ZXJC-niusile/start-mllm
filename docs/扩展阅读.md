# 扩展阅读

除了正文 10 章之外，仓库还维护了一个 `Extra-Chapter` 扩展区，用来集中放置更偏场景化、更偏工程细节的专题内容。

正文主线按 **[前言](./前言.md)“理论篇（1～4 章）/ 实战篇（5～10 章）”** 分层；Extra **不按篇切分**，按场景插在理论篇（如第 2、4 章）与实战篇（如第 5～9 章）之间阅读即可。
