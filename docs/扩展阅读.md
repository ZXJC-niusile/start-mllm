# 扩展阅读

除了正文 10 章之外，仓库还维护了一个 `Extra-Chapter` 扩展区，用来集中放置更偏场景化、更偏工程细节的专题内容。

基础篇负责首次解释概念，正文负责机制与工程方法；本页专题围绕 OCR、多图与长图讨论输入和工作流取舍。按[前言](./前言.md)选定主线后，遇到相应场景再进入专题，无需把它们全部设为先修。

## 按场景选择专题

从当前遇到的问题选择一篇专题，再回查对应正文；不必读完全部正文后才进入专题。

| 当前任务 | 专题入口 | 建议搭配正文 |
| --- | --- | --- |
| 截图、票据、合同、表格中的文字与字段 | [OCR 与文档理解](./Extra-Chapter/Extra01-OCR与文档理解专题.md) | 第二章的视觉表示、第四章的数据、第五章的评测；应用集成见第八、九章 |
| 商品多视角、版本前后对比、质检复核 | [多图输入与比较](./Extra-Chapter/Extra02-多图输入与比较专题.md) | 第三章的输入架构、第五章的评测、第八和九章的应用与工作流 |
| 长截图、长网页、长文档 | [长图处理与切块](./Extra-Chapter/Extra03-长图处理与切块策略专题.md) | 第二章的分辨率与 token、第六章的预处理与服务链路；应用集成见第八、九章 |

只需浏览文件列表时，使用[专题目录](./Extra-Chapter/README.md)。
