# 前言

## 一、这份教程要解决什么问题

本教程面向掌握 Python 基础、希望理解并使用多模态大语言模型的读者。主线是**图像与文本输入、文本输出的生成式视觉语言模型**：模型如何读取图片、怎样结合问题生成回答，以及怎样判断回答是否有图像证据支持。音频、视频与多模态生成用于扩展视野，不是本书完整实践路线。

以票据问答为例，用户上传图片并询问总金额。回答是否可靠，依赖多个环节：预处理有没有保留小字，视觉编码器提取了什么，连接器怎样把特征交给语言模型，模型生成的金额是否与原图相符。教程沿这些问题逐层展开，而不要求先记住大量模型名称。

## 三、选择一条阅读路线

### 系统理解：从 Python 基础走到 MLLM

1. 阅读[基础篇](./foundation/README.md)。00～01 解释环境、路径和形状；02～04 解释数组与学习过程；05～06 解释语言表示；07～09 解释视觉表示和多模态连接。
2. 阅读正文第一章建立任务地图，第二、三章深入视觉对齐与生成架构，第四章理解数据和训练目标。
3. 阅读第五章学习怎样评估模型，再进入第七章选择 API 或本地路线。已有可用接口时，可提前进入第七章观察输入输出。
4. 需要交互界面时读第八章，需要服务化时读第六章，需要工具工作流时读第九章。第十章帮助整理项目记录和下一步方向。

### 第一次来，先走一个最小闭环

如果你想先观察模型怎样回答图片问题，可采用体验路线：[Chapter 0](./chapter0-环境准备.md) → [基础篇 00](./foundation/00-环境命令行与Python项目基础.md)（按需）→ [第一章](./chapter1/第一章%20多模态大模型概览.md) → [第七章 API 调用](./chapter7/第七章%20动手跑通你的第一个%20VLM.md) → [第五章评测](./chapter5/第五章%20评测体系与工程选型.md)。

API 路线需要支持图像输入的接口、密钥与调用额度，无需本地 GPU。准备有使用权限的图片，保留问题和回答，检查答案中的细节能否在图里找到；占位图只能检查路径和消息格式。希望进一步理解模型时，再回到基础篇与第二、三章。

### 已有 LLM 基础

可以从第二、三章开始，重点关注视觉 token 数、连接位置和多模态监督标签。阅读中遇到框架概念，再查对应基础章节。外部课程 [thorough-pytorch](https://github.com/datawhalechina/thorough-pytorch)、[base-llm](https://github.com/datawhalechina/base-llm) 和 [self-llm](https://github.com/datawhalechina/self-llm)作为深入材料，不是进入本教程前必须全部修完的课程。

## 四、怎样阅读一个章节

先明确本章回答的问题，再沿输入、变换、输出追踪计算。遇到形状时，把每个轴的含义写清；遇到效果结论时，检查它针对哪种数据、模型和设置。基础篇中的小数字用于解释机制，正文中的模型配置应与相应版本对应。

正文第二、三章会重复部分基础概念，但增加了计算推导与真实架构对照。已经理解的定义可以快速浏览，把精力放在新增内容上。既有代码和练习是独立的实践入口；只进行知识阅读时，不要求下载模型或调用 API。

## 五、学习范围与运行边界

概念阅读只要求 Python 基础；本地推理还需要环境、设备、精度与资源知识。训练与微调属于选学，需具备相应数据与计算资源，不能由“依赖安装成功”推断训练一定能运行。环境与资源说明见 [Chapter 0](./chapter0-环境准备.md)。

本书区分三类证据：手算示例解释原理，离线测试检查指定程序行为，真实模型运行才提供相应配置下的效果和资源记录。学习时保留这种区分：能返回文本不代表答案正确，单个样本正确也不代表能够稳定处理同类任务。

## 六、预热练习

### 必做（5-10 分钟）

1. 写下你最常见的 1 个“图像 + 文本”任务场景（如截图报错、票据抽取、商品图文案）。
2. 判断这个场景中最关键的输入证据是什么（小字、布局、图标、上下文描述等）。

### 进阶（20-30 分钟）

1. 画出该场景的最小链路：输入 → 编码 → 对齐 → 生成 → 输出。
2. 写下你最担心的 3 个失败点，并说明你打算如何观测它们。

### 挑战（1-2 小时）

1. 按本页体验路线完成一次图文问答，并记录两类问题的回答差异（描述类 vs 细节类）。
2. 形成一页学习目标卡：你希望在第 4 周前做出什么 Demo、验证什么能力边界。

## 七、读完后应能解释什么

- 图像怎样变成视觉特征，这些特征怎样参与语言计算。
- 监督标签、损失和可训练参数分别控制学习过程的哪一部分。
- 如何在独立样本上检查输出，区分模型错误、数据问题和输入链路问题。
- API 调用、本地推理、服务化和 Agent 工作流分别增加了哪些职责。

是否能独立实现这些环节，还需要相应实践与反馈；阅读进度不等于运行验收。
