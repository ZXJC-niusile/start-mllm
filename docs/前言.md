# 前言

本教程围绕图像与文本输入、文本输出的视觉语言模型展开。以票据问答为例：图片先变成像素张量和视觉特征，再通过连接器参与语言计算，最后生成金额答案。正文沿这条计算链解释各模块，并讨论数据、评测与应用。

## 一、系统学习

只有 Python 基础时，先读[基础篇 00～09](./foundation/README.md)，补齐张量、求导、语言与视觉表示，再读正文第一至四章，理解任务、架构和训练目标。

进入实践时，先按[环境准备](./chapter0-环境准备.md)选择 API 或本地路线，用[第七章](./chapter7/第七章%20动手跑通你的第一个%20VLM.md)完成调用，再用[第五章](./chapter5/第五章%20评测体系与工程选型.md)检查输出。训练与微调是选学内容，不是进入推理实践的先决条件。

已有结果后，按需要继续：第六章讨论服务化，第八章构建交互 Demo，第九章组织工具工作流，第十章整理项目目标与迭代记录。全部章节见[阅读目录](./README.md)。

## 二、先体验一次图文问答

已有支持图像输入的接口、密钥与调用额度时，可先读[环境准备](./chapter0-环境准备.md)的 API 路线，再进入[第七章](./chapter7/第七章%20动手跑通你的第一个%20VLM.md)。不熟悉终端和路径时，先读[基础篇 00](./foundation/00-环境命令行与Python项目基础.md)。这条路线无需本地 GPU。

使用一张自己能核对内容的图片，按第七章保存问题、输出与图像证据，再进入第五章。占位图只用于检查请求链路。需要理解模型内部计算时，返回基础篇以及正文第二、三章。

## 三、已有 LLM 基础

从[第二章](./chapter2/第二章%20视觉编码器与跨模态对齐.md)和[第三章](./chapter3/第三章%20多模态生成架构.md)开始，重点追踪视觉特征的数量与宽度、连接位置和多模态监督标签。遇到不熟悉的基础概念，按[基础篇目录](./foundation/README.md)查阅。

[LLM 基础速通](./llm-基础速通.md)用于复习，[术语表](./术语表.md)用于速查；OCR、多图和长图等任务见[扩展阅读](./扩展阅读.md)。它们不构成另一套必修顺序。

需要更深入的框架或语言模型材料时，可参考 Datawhale 的 [thorough-pytorch](https://github.com/datawhalechina/thorough-pytorch)、[base-llm](https://github.com/datawhalechina/base-llm) 与 [self-llm](https://github.com/datawhalechina/self-llm)。

## 四、如何理解示例结果

手算示例解释计算机制，离线测试检查指定程序行为，真实模型运行记录描述特定配置下的输出与资源使用。三者不能互相替代；阅读时以章节注明的验证范围为准。基础篇中的小数值可以手算核对，模型示例则需对照环境、权重和输入设置。
