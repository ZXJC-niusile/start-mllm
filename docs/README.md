## 首次阅读

只有 Python 基础、希望系统理解原理时，从下方基础篇 00～09 顺序阅读，再进入正文第一至四章。希望先体验图文接口时，按[前言的最小闭环](./前言.md#quick-api-route)进入第七章与第五章。LLM 基础速通用于复习，专题用于按问题查阅。
